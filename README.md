Стресс-тестирование нормативного капитала банковского сектора Республики Беларусь
Проект реализует модель макрофинансового стресс-тестирования нормативного капитала банковского сектора на Python.
  NCAP — достаточность нормативного капитала 
  R — рентабельность 
  RATE — процентная ставка 
  LCR — показатель ликвидности 
  CURRENCY — валютный курс 
  IPI — индекс промышленного производства 
  IPC — индекс потребительских цен 
  C — константа
В модели используются:
• VARX(1) для прогнозирования R, LCR и RATE;
• ARDL-модель для расчета нормативного капитала NCAP;
• заданный 12-месячный стресс-сценарий по IPC, IPI и CURRENCY;
• bootstrap Monte Carlo с 10 000 симуляций.
Коэффициенты ARDL были первоначально оценены в EViews и используются в Python как фиксированные параметры модели.
